# HARUN Noir — Digital Sanctuary

Personal website featuring a digital sanctuary, 42 School skills profile, and voice acting showcase.

## Pages

- **index.html** — Main hub with social links (YouTube, GitHub, Instagram, X, Discord, Email, Mastodon, Bluesky)
- **42.html** — Redirect to the 42 School skills section
- **voice.html** — Redirect to the voice profile and planned demo reels

## Design

- Dark bronze aesthetic (`--void`, `--gold`, `--amber` palette)
- Custom cursor with trailing ring
- Film grain overlay and layered atmospheric background
- Quiet text navigation and optional ambient audio
- Minimal, old-print-inspired presentation

## Structure

```
├── index.html       # Home / Sanctuary
├── 42.html          # 42 school portfolio
├── voice.html       # Voice acting page
├── style.css        # Shared styles (all pages)
├── profile.jpg      # Profile photo
└── asset/
    ├── background.jpg
    ├── logo.png     # Favicon
    └── sounds/      # Optional ambient audio
```

## Usage

Open `index.html` in any browser. No build step or server required — static HTML/CSS/JS.

## Fonts

- **IM Fell English** — body and italic text, based on historical English printing types
- **IM Fell English SC** — names, headings, and navigation
