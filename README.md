# HARUN Noir — Digital Sanctuary

Personal website featuring a digital sanctuary, 42 school portfolio, and voice acting showcase.

## Pages

- **index.html** — Main hub with social links (YouTube, GitHub, Instagram, X, Discord, Email, Mastodon, Bluesky)
- **42.html** — 42 school portfolio and projects
- **voice.html** — Voice acting demo reels and voice profile

## Design

- Dark bronze aesthetic (`--void`, `--gold`, `--amber` palette)
- Custom cursor with trailing ring
- Film grain overlay and layered atmospheric background
- Smooth loader animation and ambient audio generator
- Glassmorphic UI elements with blur-backdrop

## Structure

```
├── index.html       # Home / Sanctuary
├── 42.html          # 42 school portfolio
├── voice.html       # Voice acting page
├── style.css        # Shared styles (all pages)
├── profile.jpg      # Profile photo
└── asset/
    └── logo.png     # Favicon
```

## Usage

Open `index.html` in any browser. No build step or server required — static HTML/CSS/JS.

## Fonts

- **Cinzel** — headings
- **Cormorant Garamond** — body, bio, italic accents
- **Inter** — general UI
- **JetBrains Mono** — tags, badges
